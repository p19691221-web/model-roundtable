# 模型圓桌

同一個問題，先讓 2～4 個模型各自獨立回答，再互相挑錯，最後由你判斷。單一網頁，不需安裝。

## 流程

1. **各自回答**：模型同時作答，互相看不到彼此的回答。
2. **交叉批評**：每個模型只看其他人的回答（匿名為 A、B、C），指出沒有來源的說法、推論跳躍、迎合或誇大、彼此矛盾之處，不重新作答。
3. **你判斷**：寫下你採信什麼、核對了哪些來源，下載或複製整輪紀錄（Markdown）。

## 使用

- 需要 [OpenRouter](https://openrouter.ai) 的 API 金鑰（依用量付費）。一把金鑰可呼叫多家模型。
- 在「設定」填金鑰與模型 ID；按「載入可用模型清單」可搜尋選擇。
- 金鑰只存在你自己的瀏覽器（勾選「記住」時）。

## 限制

- 問題與回答會經過 OpenRouter 送到各模型廠商，不要放入機密資料。
- 模型都同意不代表正確；同家或相近訓練的模型容易一起附和。重要事實請自己核對原始來源。
- 不儲存歷史紀錄，每一輪請自行下載。

## 部署

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
